## Getting Started

Drop any `.md` file into a category directory and it will appear automatically on the index page.

- New **categories** are picked up when you create a new directory under `content/`
- New **articles** appear as soon as you save a `.md` file into a category
- The **date** shown is taken from the file's last-modified timestamp
